# Crit 4 Reflection

## What was the breakthrough that moved the work forward?

The breakthrough was testing the first prototype myself instead of only checking whether the code and tests worked. My first version was a theremin controlled by mouse or touch movement. It worked technically and passed the checks, but when I opened the page, I found that the design was too empty and the interaction was too abstract. It was not immediately clear what the user was supposed to do or that the page was meant to be a musical instrument.

I then looked at some existing browser instruments and changed the design into a visible piano synthesizer. This made the interaction much easier to understand and also easier for me to test. I later expanded the keyboard to two octaves and added waveform, tone and octave controls.

## What did this work change about who I want to be as a software developer?

This work reminded me that passing automated tests does not mean that an interactive design is finished. I still need to use the result myself and decide whether the interface is clear and whether the interaction actually works well for a user.

I also found that the agent was useful for checking technical details. During a later review, it found problems with the black-key positions and the mobile layout. The agent can help with implementation and checking, but I still need to make the main decisions about the design and whether the final result is good enough to keep.
